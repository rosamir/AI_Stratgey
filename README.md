# מדריך אינטראקטיבי: הטמעת בינה מלאכותית בארגון

מדריך דיגיטלי אינטראקטיבי המבוסס על תוכנית אסטרטגית להטמעת בינה מלאכותית, מנוסח בגרסה גנרית המתאימה לכל ארגון (ולא לגוף ספציפי).

הקונספט: **חדר בקרה** - ניווט צדדי קבוע, פרקים ברורים, וכלים אינטראקטיביים אמיתיים (לא קישוט): מפת דרכים דו-ממדית עם טאבים וסינון, טבלת יוזמות מסוננת לפי תחום, אקורדיונים לעקרונות וסיכונים, ובדיקת מוכנות ארגונית עם ציון מחושב.

## הרצה מקומית

הפרויקט הוא אתר סטטי (HTML/CSS/JS ללא build step). כדי להריץ אותו מקומית:

```bash
cd site
python3 -m http.server 8080
```

ואז לפתוח בדפדפן: `http://localhost:8080`

## מבנה

- `index.html` - מבנה הדף וכל הסקשנים
- `styles.css` - עיצוב מלא, כולל רספונסיביות ונגישות
- `data.js` - כל תוכן המדריך (גנרי, ללא אזכור ארגון ספציפי)
- `app.js` - רינדור התוכן ולוגיקת האינטראקציה
- `assets/` - תמונת ההכרזה על הקמת מרכז ה-AI
